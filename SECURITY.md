# Security Policy

## Reporting a vulnerability

Please report security issues privately to Yele Zhong (https://github.com/DEOWL-kan).

Do not open public GitHub issues for suspected vulnerabilities.

For non-security bugs, use the issue tracker: https://github.com/DEOWL-kan/spaceflight-news-sdk/issues

## Scope

This policy applies to the generated Yele Zhong SDK packages published from this
repository (npm, PyPI, Packagist, RubyGems, LuaRocks, and the Go module).

This is an unofficial SDK for the Spaceflight News public API, generated by
Yele Zhong. It is not affiliated with, endorsed by, or sponsored by the upstream
API provider.
